# LearnUnlock-Datasets
The custom math, humanities, political, and teen safety datasets used with GEPA to optimize the tutoring prompt.

WARNING: The political and teen safety datasets contain sensitive topics and language.

## Dataset Descriptions
We designed the datasets for GEPA prompt optimization. 
Each chat contain a student message or conversation ending in a student message.
With the conversation history, the tutor LLM can generate a response.
Using an LLM-as-a-judge and/or other criteria, 
the tutor prompt can be optimized based on the response.
